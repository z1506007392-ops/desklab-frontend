# Web design guidelines

Review the files the user names. If they name none, ask which files to read.

Read `references/command.md` in this skill folder and apply it to those files. That file is the rules and the audit output format. It is a local copy. Do not fetch a fresh copy from the network.

Report findings in the output format that file specifies (`file:line`, grouped by file, terse).
